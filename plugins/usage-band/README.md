# usage-band

Bande au-dessus du champ de saisie : **Contexte** (% et tokens), **Modèle** actif (et celui des sous-agents Explore, checker… quand ils tournent), **Cache** (compte à rebours avant refroidissement, 1 h), **Session 5 h** et **Semaine** (% utilisé + temps avant reset). Palette alignée sur aurora-noir. Lecture seule : aucun réseau, aucun fichier, aucun processus ; elle lit les chiffres du moteur et dessine.
Le cache est une estimation à partir du dernier tour (TTL fixé à 1 h), pas une valeur de l'API.
